# 代码分析报告

本技能提供报告组织约定。用户显式调用本技能时也按报告任务处理；用户指定的范围、格式及后续修正优先。

## 输入与输出

- 从自然语言读取分析对象、侧重点和可选的 `output_path`，无需填写参数模板。类型重名且无法从上下文取舍时再确认。
- 分析范围以用户指定对象为主；为解释实际调用链，可以读取相关定义和调用方，并在报告中说明扩展范围。
- 输出路径与是否落盘遵循根目录 [AGENTS.md](../../../AGENTS.md)；未指定路径时使用 `cursor_output/<主题>-代码分析报告.md`，用户明确只要聊天回答时不落盘。

## 报告约定

按下列结构组织，用户另有格式要求时采用用户格式。章节内容只保留与对象有关的部分，不为凑齐模板臆测设计模式、性能问题或改进项。

```markdown
# 代码分析报告：<分析对象>

## 职责与边界
分析范围、对外能力，以及由其他模块承担的职责。

## 关键实现与调用关系
主要入口、实际调用方、生命周期及关键数据流；按职责组织，避免逐文件复述。

## 使用方式与约束
启动或调用方式、必要配置、资源或事件的持有与释放条件。无适用内容时省略。

## 已确认的问题与待确认项
区分代码证据、推断和需要运行验证的内容。没有发现时省略。
```

关键结论附文件路径和行号；落盘文档使用仓库相对路径描述来源，聊天按当前客户端支持的文件链接展示。依赖关系以实际类型、调用和配置引用为依据，不能仅凭 `using` 推断。
