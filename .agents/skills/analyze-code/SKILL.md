# 代码分析文档

按本技能对指定范围做结构化代码分析，并输出可归档的 Markdown 报告（简体中文）。

## 何时使用

- 用户提到：代码分析、模块文档、设计思路、架构说明、技术说明、读代码、梳理职责等
- 用户给出文件路径、文件夹路径或类型名并要求总结功能与设计

## 调用时复制以下块（可选，优先于零散描述）

用户可将本节复制到首条或置顶消息并填写；**以块内显式给出的字段为准**。

```markdown
## 本次分析参数
- target: （必填：单文件路径 | 文件夹路径 | 类型名/类名）
- target_file: （可选：类名分析时建议填写定义所在文件路径）
- search_root: （可选：仅在按类名搜索时限定目录，默认 code_root）
- code_root: （可选：未填则用当前工作区/仓库根；文件夹型 target 时分析范围以 target 为边界）
- context: （可选：项目背景、已知架构、依赖说明）
- focus: （可选：如性能、扩展性、线程安全）
- output_path: （可选：相对仓库路径，如 docs/analysis/foo.md；未填则只在对话中输出）
```

**优先级**：`本次分析参数` 块 > 同轮对话中的其他说明 > 合理默认（`code_root` 为工作区根；`target` 为文件夹时以该文件夹为分析边界）。

## 输入变量说明

| 变量 | 说明 |
|------|------|
| target | 单文件、模块目录，或核心类型名（C# 类等） |
| target_file | 已知类定义文件时填写，避免歧义 |
| search_root | 与 `code_root` 类似，用于缩小按名搜索范围 |
| code_root | 推断依赖、相对路径时的默认根 |
| context | 与代码对照验证的外部信息 |
| focus | 报告侧重点 |
| output_path | 若指定则写入该文件（目录需存在或创建） |

**类名型 target**：若仅提供类型名且无 `target_file`，先用搜索工具在 `search_root` 或 `code_root` 下定位定义文件，再分析；多义时列出候选并简短确认或按调用方说明取舍。

**缺失信息**：若无法确定 `target` 或范围，先根据仓库推断；仍不确定则向用户追问或使用 AskQuestion。

## 分析流程

1. **理解范围**：根据 `target` 判定是文件、目录还是类型名；目录则列出主要文件并判断入口（如 `Main`、`*State`、`*Manager`、模块 Facade）；类型名则先定位定义与主要引用点。
2. **提取功能**：识别对外 API、公共方法/属性、事件、配置项、序列化字段等，按重要性排序。
3. **分析设计思路**：模块划分、生命周期与初始化、数据流、设计模式、扩展点、与周边模块的耦合方式。
4. **验证上下文**：若有 `context`，标注与代码一致或不一致之处。
5. **输出文档**：严格使用下方「输出格式」模板；若提供 `output_path`，将完整报告写入该路径并在对话中说明已写入。

## 执行约束

- 结论需有代码依据；关键断言处使用仓库内的代码引用格式（`startLine:endLine:filepath`）。
- 不确定处明确写「假设」或「待确认」，不臆造行为。
- 报告正文使用**简体中文**（专有名词可保留英文）。

## 输出格式

严格使用以下 Markdown 结构（将 `{target}` 等替换为实际值）：

```markdown
# 代码分析报告：{target}

## 1. 概述
- **分析对象**：{对 target 的具体描述，含路径或类型}
- **主要职责**：一句话说明核心职责

## 2. 功能清单
- **功能点 1**：描述 + 对应入口（方法/属性/接口）
- **功能点 2**：…
（按重要程度排序）

## 3. 设计思路
### 3.1 整体架构
- 模块划分（可辅以 Mermaid，节点 ID 勿用空格）
- 核心类/文件职责

### 3.2 关键实现细节
- 初始化方式（如 Awake/Start/构造函数/静态初始化）
- 数据流（输入 → 处理 → 输出）
- 使用的设计模式（如单例、观察者、状态等）

### 3.3 依赖关系
- 模块内依赖
- 外部依赖（引擎 API、第三方、项目公共模块）

## 4. 使用方式
- 如何启动/调用
- 配置项说明（如有）

## 5. 注意事项与潜在问题
- 已知限制
- 性能/安全注意点
- 迁移或复用时注意点

## 6. 分析总结
- 优点
- 可改进点（如有）
```
