# 框架知识库概要

索引：接口名、目录名与功能关键词的对照。范围是 `Assets/HotScripts/Framework`。运行时快捷入口是静态类 `G`。

## 宏观分层

根目录：`Assets/HotScripts/Framework/`。

| 位置 | 角色 | 依赖 |
|------|------|------|
| `Framework/` | 跨项目框架 | — |
| `BaseUtility/` | 公共程序集 | 不依赖 Services、Modules |
| `Services/` | 有接口约束的、业务无关的底层服务 | 可依赖 BaseUtility；不依赖 Modules |
| `Modules/` | 业务功能模块，偏数据 | 可依赖 BaseUtility、Services，以及其它 Module |
| `Subassembly/` | 高度内聚、几乎不依赖框架、可单独取出编译的子程序，以热更源码存放 | — |
| `GameEnv/GEnv` | 全局环境。唯一单例，拼装 Service、Module、Managers | — |
| `GameEntry` | AOT 调用热更程序集的入口。创建 GEnv，并转发帧驱动 | — |

运行时实例是 `GEnv` 的项目子类（当前为 `GEnvProduct`），经 `GEnv.Inst` 持有。`GEnv` 内部分三层：`Services`、`Modules`、自由管理器（现有 `EnvStateManager`）。服务换实现时满足对应接口。模块用 `[ModuleAutoRegister]` 收集。

帧入口在 `GameEntry`，转发到 `GEnv`，再由 `EnvDriver` 分发。

| 名字 | 关键词 |
|------|--------|
| `G` | 服务与模块的静态入口、日志 |
| `GEnv` / `GEnvParam` | 环境单例、日志与种子等启动参数 |
| `EnvDriver` | Fixed / Update / LateUpdate / Pause / Focus / Gizmos / OnGUI |
| `EnvStateManager` | 环境状态切换 |
| `ConsoleHostBridge` | 命令行宿主的日志、命令、按键 |
| `KLogger`（`OldAdaptation.cs`） | 旧日志入口，转到 `G` |

## `.Unity` 规则

Unity 侧代码用名称标记，供分离工具和纯 C# 编译排除。判定在 `XEditor.UnityPartingTool`（菜单 `XTools/打开 UnityParting 工具窗口`）。

命中条件（大小写不敏感）：

- 目录名以 `.Unity` 结尾：整棵目录都是 Unity 侧。例：`SvcAsset.Unity`、`Engine.Unity`。
- 去掉扩展名后的文件名以 `.Unity` 结尾：该文件是 Unity 侧。例：`Foo.Unity.cs`、`Foo.Console.Unity.cs`。
- `.meta` 随主资源移动，不单独匹配。

分离是剪切，保持相对 Root 的路径。先移动最外层 `.Unity` 目录，再移动落在这些目录之外的单个 `.Unity` 文件。默认 Root 为 `Assets/HotScripts`，默认 Target 为 `Assets/HotScripts/UnityParting`。

写法：与引擎无关的声明留在普通文件；Unity API 放在同类型的 `partial`，文件名为 `*.Unity.cs`。整包依赖 Unity 时用 `Xxx.Unity/` 目录。

纯 C# 工程（PureGameEnv）排除上述两类路径，并另外排除名为 `Editor` 的目录。命令行编译符号为 `CONSOLE_CLIENT`。与之成对的命令行文件使用 `*.Console.cs`（该后缀本身不参与 `.Unity` 匹配）。

## Services

目录在 `Framework/Services/`。公共生命周期接口是 `IService`（`Shutdown`）。`ITypeCacheService`（按特性或名字取类型）只有接口，没有对应 `Svc` 目录。

| 目录 | 接口 | 入口 | 关键词 |
|------|------|------|--------|
| `SvcAsset.Unity` | `IAssetService`、`IAssetLoader` | `G.Asset` | 资源加载、释放、原始文件 |
| `SvcAudio.Unity` | `IAudioService`、`IAudioStereo` | `G.Audio` | Bank、事件播放、Track 静音、立体声 |
| `SvcCamera.Unity` | `ICameraService` | `G.Camera` | Base 相机、UI Overlay |
| `SvcConfig` | `ITableConfigService` | `G.TableConfig`、`G.Tables` | Luban 配表 |
| `SvcCoroutine` | `ICoroutineService`、`ICoroutineHandler` | `G.Coroutines` | 协程启动、暂停、按 owner 停止 |
| `SvcCustomLogic` | `ICustomLogicService` | `G.CustomLogic` | 逻辑配置、创建与销毁、变量环境 |
| `SvcDevice.Unity` | `IDeviceProfileService` | `G.DeviceProfile` | 硬件评分、画质档、帧率 |
| `SvcLocalization` | `ILocalizationService`、`Language`、`ILocalizationLanguageCfg` | `G.Localization`、`G.GetI18N` | 多语言文本 |
| `SvcPool` | `IPoolService` | `G.SharedPool` | 纯 C# 对象池 |
| `SvcPool.Unity` | `IGameObjectPoolService`、`IGameObjectRentAsync` | `G.GOPool` | GameObject 租还、按地址异步租用 |
| `SvcPoolFx.Unity` | `IFxPoolService`、`FxHandle` | `G.FxPool` | 特效生成、寿命、挂点、存活上限 |
| `SvcRandom` | `IRandomService` | `G.Random` | 种子随机：整数、浮点、布尔 |
| `SvcTickTime` | `ITickTimeService` | `G.TickTime`、`G.deltaTime` | 帧间隔、timeScale、倍速、减速 |
| `SvcTimer` | `ITimerService` | `G.Timer` | 定时器添加、移除 |
| `SvcUI.Unity` | `IUIService`、`UILayerId`、`IScaleable`、`ICloseClear` | `G.UI` | 面板打开、关闭 |
| `SvcValueEvent` | `IValueEventService`、`IValueEvent` | `G.ValueEvent` | 值类型事件派发与监听 |

`SvcTickTime` 的 Unity / 命令行实现分文件：`TickTimeService.Unity.cs`、`TickTimeService.Console.cs`。`SvcCoroutine` 的 MonoBehaviour 宿主在 `CoroutineHandler.Unity.cs`。

项目侧（`Assets/HotScripts/Product/Services/`，不在 Framework 内）：

| 目录 | 接口 | 入口 | 关键词 |
|------|------|------|--------|
| `SvcInput.Unity` | `IInputService` | `G.Input` | 键鼠、虚拟轴、虚拟按钮 |

## Modules

目录在 `Framework/Modules/`。取模块：`G.Module<T>()`。

| 类型 | 关键词 |
|------|--------|
| `Module` / `IModule` | 生命周期：Init、Start、Shutdown；数据 InitData / ClearData |
| `ModuleManager` | 注册、获取、注销 |
| `ModuleAutoRegister` | 按特性收集模块 |
| `ModuleDataType` | 数据寿命：Global、Player、Scene |
| `IPlayerStateModule` | 登录、登出 |
| `INetStateModule` | 断线 |
| `ISceneStateModule` | 进入场景、离开场景 |
| `IApplicationStateModule` | 应用暂停 |
| `IResettable` | 重置 |

已自动注册的模块：

| 模块 | 关键词 |
|------|--------|
| `ModuleWorlds` | 游戏世界。`IWorldsConfig`、`MainWorld` |
| `ModuleDebug` | 调试模块 |
| `ModuleGM` | GM 功能块插装 |

`ModuleGM` 的块与视图：

| 名字 | 关键词 |
|------|--------|
| `IGmBlock` | 功能块：Id、标题、页签 |
| `GmGameSpeed` | 游戏倍速 |
| `GmStaticAction` | 静态调试动作 |
| `IGmEditorDrawer` | 编辑器窗口 |
| `IGmConsoleBlock` | 命令行命令 |
| `IGmCanvasBlock` | 运行时调试窗 |

项目侧扩展（`Assets/HotScripts/Product/Modules/`）：`ModuleDebug`、`ModuleGM` 的 partial；`ModuleDemo` 为演示模块，不参与自动注册。
